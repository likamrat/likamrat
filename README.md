# Hi, I'm Lior

I'm a hands-on technical architect in the Microsoft Work IQ Product Group. My work includes figuring out how AI agents connect to tools and data, and how to test whether they do what people need.

My background is in distributed systems, cloud, and edge. I enjoy making complex systems easier to build and run through automation. Developer experience and developer relations are part of my work through open-source collaboration, technical writing, and public speaking.

## Projects and resources

- [Work IQ Request Explorer (WIRE)](https://github.com/likamrat/wire): See recorded human and agent prompts alongside the Work IQ calls and results they produced. Use those interactions to find failures and write better eval cases. Search runs on your device.
- [GitHub Copilot Canvas Apps](https://github.com/likamrat/ghcp-canvas-apps): Personal extensions that open alongside your chats. Find files with Artifacts, save ideas with Thoughts, check session capacity with Context Monitor, or find past captures with Screenshots.
- [Agent Skills](https://github.com/likamrat/skills) - Workflows for AI agents, including customer discovery, evaluation, and technical readouts.
- [Arc Jumpstart](https://jumpstart.azure.com/): An open-source program I created for cloud and edge deployment automation and hands-on learning.
